# Видео-сайт (только для телефона)

При входе на сайт сразу запускается **video1.mp4**.
Когда оно заканчивается, включается **video2.mp4** — и играет в бесконечном цикле.

## Структура проекта

```
video-site/
├── index.html        — страница с двумя видеоплеерами
├── README.md         — это описание
├── css/
│   └── style.css     — стили (видео на весь экран, кнопки)
├── js/
│   └── main.js       — логика: video1 → video2 (loop)
└── videos/
    ├── README.txt    — подсказка, что сюда класть
    ├── video1.mp4    ← ваш файл (играет один раз)
    └── video2.mp4    ← ваш файл (зациклено)
```

## Как запустить

1. Положите свои видео в `videos/` под именами `video1.mp4` и `video2.mp4`.
2. Откройте `index.html` в браузере (или запустите `python -m http.server` в папке проекта).

## Мобильная версия

- Видео на весь экран, учитывается адресная строка браузера (`100dvh`) и «чёлка» (`safe-area`).
- Кнопки крупные, под палец (от 44 px).
- На компьютере (широкий экран + мышь) вместо видео показывается сообщение «Откройте на смартфоне». Планшеты и телефоны открывают сайт как обычно.
- Видео ставится на паузу, если свернуть вкладку, и продолжается при возврате.

## Важно

- Браузеры разрешают автозапуск только **без звука**, поэтому видео стартуют с выключенным звуком.
  Звук включается кнопкой справа внизу.
- Если автозапуск всё же заблокирован, появится кнопка «Нажмите, чтобы начать».
- Чтобы изменить имена файлов — поправьте атрибуты `src` в `index.html`.
